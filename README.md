# OSINT Toolkit

A growing collection of open source intelligence (OSINT) tools for
investigation, analysis, and research, from simple command line utilities
to more advanced, AI-assisted tools.

| Tool | Description |
|------|-------------|
| [image-metadata-manager](image-metadata-manager) | Inspect, export and strip EXIF metadata, with GPS decoding |
| More tools | Coming soon |

## Requirements
Python 3.10+. Each tool lists its own dependencies in its folder.

## Ethical use
These tools are for learning, research, and authorized investigations only.
